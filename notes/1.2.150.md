# No Render button: stop the game drawing while the bot runs
- A new **No Render** button sits in the NIX header, between the version and **Wide**. It makes the game stop drawing and covers it with a black screen; combat and pet pickup keep running. Press **Render** to bring the picture back, no reload needed.
- The black screen stays up when the NIX panel is minimised or hidden.
> Added by Bigz (PR #24). Tested in simulation only, not in a live game. It relies on how the current client handles a hidden tab, and the game may still draw while a world is loading. GPU memory stays allocated, and the saving has not been measured.
