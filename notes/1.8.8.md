# Assistant (local): ask about your session

- Settings page gains an "Assistant (local)" group: point it at your own OpenAI-compatible server (LM Studio and the like) on this machine, test the connection, then "Explain my session" or ask a question.
- Only the redacted snapshot the bug report uses is sent (no names, chat or locations); leave the model empty to use the first one your server lists; nothing else about the game ever leaves the page.
- Off unless you configure it: an empty endpoint changes nothing, a failure or timeout only shows a message, and the bot never waits on the assistant.
- Also ships the local LLM tooling for developers (tools/llm: bench, diagnostics eval, journal distiller) and opens upstream PR #97 for the settings groundwork.

> Fork-only layer (upstream PR #97 covers the endpoint groundwork). Tested in simulation only: integration suite with a stubbed server, plus live requests against the developer's LM Studio in tools/llm — not exercised inside a live game session yet.
