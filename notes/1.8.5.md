# Fork synced with upstream 1.2.223

- Pet loot on town trips sells again: the server refuses sales straight from the pet's bag, so the bot now moves each sellable pet item to a free slot in your bag first (and the full bag itself is sold before the pet loot).
- Town trips no longer hang before the return scroll: a game that never settles gets a one-minute cap and a clean stop instead of waiting forever; an unexplained triple refusal now says the game itself may be refusing the scroll.
- Town trips no longer stop at the smith after a supply skipped on purpose (merchant does not sell it, or gold ran short).
- New hunt option "Spare engaged giant/party below % HP (0 = off)" for the "Normal & champion only" avoidance mode: a giant or party monster another player is fighting is skipped once its health is at or below the cutoff (default 50, set 0 to turn off).
> The upstream features come from upstream releases 1.2.219-1.2.223; this sync was checked with the offline test suite only.
