# Clearer mall roles: scrolls with the potions, merchant-first thresholds
- Keeping the 20% damage and resistance scrolls active is now set under Automatic potion use, right beside the speed scroll it mirrors; the Item mall section only refills the stock.
- The mall potion thresholds now default below the merchant restock marks, so the merchant stays the primary source and the mall only steps in when that was not enough. Raising a mall mark above the merchant one flips that item to silk-first, for wallets that prefer it — the thresholds themselves express the priority.
