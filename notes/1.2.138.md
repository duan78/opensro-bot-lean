# Walking no longer gets stuck on obstacles
- When the character stops against something while walking (return to the hunting spot, town trips, potion restocking and trade runs), the bot now notices after a few seconds, marks the spot ahead as blocked and plans a way around it.
- It tries a few times at one place. If it still cannot get past, it stops with a clear message ("an obstacle blocks the way") instead of standing there.
- Normal move commands only: no teleporting and no collision bypass.
> Tested in simulation only (an invisible object the collision map does not know about); not yet confirmed on the live server.
