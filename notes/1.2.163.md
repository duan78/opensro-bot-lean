# Auto-start points Classic users to the right page
- When auto-start runs with no saved hunting spot, the warning now names both pages: "Set one in Combat → Hunt area (Training place in the Classic window)."
- Before, it only mentioned the Combat window, which Classic users do not have.
- Same warning toast as before, shown about 5 seconds after the character enters the game.
