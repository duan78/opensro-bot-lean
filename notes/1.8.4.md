# Fork synced with upstream 1.2.218

- On a town trip, better gear you carry is worn and the piece it replaces is stored in the warehouse (off by default, Loot > Wear better gear).
- A spot with no XP can move hunting to the next level spot instead of returning to town.
- The wait for a party resurrection before reviving in town is configurable.
- Alert chimes: a player near, your own death, a level up and a unique in view (each off by default).
- Item names, icons and codenames are cached from the server wire when the game data files are not served, so item rules and Star checks work there; Don't pick up Star gear waits for an item the catalogue has never seen.
> The upstream features come from upstream releases; this sync was checked with the offline test suite only.
