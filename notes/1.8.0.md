# Auto Quest

- New Quest page: quests are done automatically. The quest markers the game itself sends route the bot - it walks to the quest NPC, accepts the quest, and turns it in when the journal says the objective is met.
- Quests the reward window can close are rewarded with the quest window's own command, without walking back to the NPC. A refused reward waits a minute and then falls back to its NPC.
- Which dialogue row belongs to which quest, and which monster kills advance which quest, are learned while playing - no quest database is shipped. Learned monsters are hunted first while their quest counts.
- The quest list shows each active quest's count and a Skip button; codename include/exclude patterns filter which quests are taken.
- Turn-ins never guess between several unknown dialogue rows (a wrong Yes would accept another quest); such an NPC is left with a message instead.
- Everything here was tested against a simulated game state only: the quest marker, journal, and NPC dialogue contracts were read from the game's own source. The opcodes and dialogue flow have not been verified on the live server yet.
