# Back to the hunting spot by reverse scroll, not on foot, after logging in dead
- When a character was dead at login and wakes up in town, the bot no longer tries to walk from town to the hunting spot. With town services set up it does the town trip (potions, repair, warehouse) and then uses the reverse return scroll, the same way it does after dying while hunting.
- The same applies when hunting resumes after a reconnect and the character is standing in that town.
- Outside town nothing changes: small returns inside the hunting area still walk as before.
> Tested in simulation only; not yet confirmed on the live server. Needs town services saved and a reverse return scroll in the bag.
